# Play Console Field Order

最後更新：2026-04-18

這份是 Google Play Console 建議提交順序，照這個順序填最快。

## Step 1. 先準備檔案
- 最新 AAB
- App icon
- 截圖
- Privacy Policy URL
- Contact Email
- release notes

## Step 2. Store listing
先填這些最直觀欄位：
1. App 名稱
2. 短說明
3. 完整說明
4. 類別
5. 聯絡資訊
6. 圖示
7. 截圖

## Step 3. App content
再填合規欄位：
1. Privacy Policy
2. App access
3. Ads
4. Data safety
5. Content rating
6. Target audience

## Step 4. Testing / Release
1. 進 Internal testing 或 Closed testing
2. Create new release
3. 上傳 AAB
4. 貼 release notes
5. Review release
6. Start rollout

## Step 5. 最後檢查
- versionCode 沒倒退
- release notes 正確
- 截圖無誤
- Privacy Policy 可開
- 聯絡資訊正確

## 建議
如果今天第一次送，先用 Internal testing，比直接 Production 穩很多。
