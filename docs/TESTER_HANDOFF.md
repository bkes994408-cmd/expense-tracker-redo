## 2) 本版重點功能

- 首次啟動為乾淨資料（不帶 demo 記帳資料）
- 交易：新增 / 編輯 / 刪除、月份切換、搜尋排序與分類篩選
- 定期帳目：新增、啟用停用、編輯、刪除（可改下次扣款日期）
- 設定：幣別、月起始日、提醒/備份開關、清除全部資料
- CSV 匯出：
  - 支援範圍 `當月 / 全部 / 分類`
  - 匯出前會顯示「預計筆數」與「下載檔名預覽」
  - 無資料時會阻擋匯出並提示

## 3) 已知限制

- 計算機只支援 `+ - * /`、小數、正負號；不支援括號與進階運算
- 設定頁「評分 App」目前是提示訊息，尚未導向商店頁
- CSV 匯出已驗證流程與內容，實機下載資料夾路徑仍請依裝置系統行為確認

## 4) 建議測試重點（精簡版）

1. **安裝與啟動**
   - 安裝後可開啟，不閃退
   - 首次啟動無預設示範資料

2. **交易與定期帳目**
   - 新增一筆支出與一筆收入
   - 編輯與刪除交易
   - 定期帳目可編輯「下次扣款日期」並立即更新顯示

3. **報表 / 預算 / 目標**
   - 修改任一分類預算，重開 app 後仍保留
   - 新增目標、快速存入、刪除目標

4. **設定與 CSV 匯出**
   - 切換 style / dark mode / 幣別 / 月起始日
   - CSV 匯出測 3 種 scope：當月、全部、分類
   - 確認檔名預覽會隨 scope/category 變化
   - 無資料或未選分類時，匯出按鈕應 disabled 或明確提示

完整清單請參考：`docs/DEVICE_QA_CHECKLIST.md`

## 5) Bug 回報格式（建議）

請盡量用以下格式回報，方便快速定位：

- **標題**：一句話描述問題
- **環境**：手機型號 / Android 版本 / App 版本（或 APK 時間）
- **重現步驟**：1, 2, 3...
- **預期結果**：你原本預期發生什麼
- **實際結果**：實際看到什麼
- **發生頻率**：每次 / 偶發（約幾次會出現一次）
- **附件**：截圖、錄影、log（若有）

範例：
- 標題：CSV 分類匯出後檔名未帶分類
- 環境：Pixel 7 / Android 14 / debug APK（2026-04-11）
- 步驟：設定 → 匯出 CSV → 選「分類」與「交通」→ 匯出
- 預期：檔名包含 `category-交通`
- 實際：檔名只顯示 `month`
- 頻率：每次都會
- 附件：錄影 1 段
