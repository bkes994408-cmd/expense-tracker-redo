# Screenshot Checklist

最後更新：2026-04-18

這份清單用來準備 Android / iPhone 商店截圖。

## 建議先準備的畫面
1. Home 總覽頁
   - 有月度摘要
   - 有預算 / 目標資訊

2. Transactions 交易列表
   - 顯示搜尋 / 篩選 / 排序狀態
   - 有收入與支出混合資料

3. 新增交易 Modal
   - 顯示分類、金額、備註預設選項

4. Recurring 定期帳目
   - 顯示項目列表與下次扣款日期

5. Reports 報表頁
   - 顯示月支出趨勢
   - 不要用空狀態當商店主圖

6. Budget / Goals
   - 顯示預算編輯或目標進度

7. Settings
   - 顯示幣別、月起始日、CSV 匯出區塊

8. CSV 匯出
   - 顯示範圍、筆數預覽、檔名預覽

## 截圖前建議
- 用一致的測試資料
- 避免空畫面作為主要商店圖
- 檢查深色 / 淺色模式是否要分開截
- 檢查字沒有被裁切
- 若要上架，先確認沒有私人資料

## Android 建議
- 至少準備手機尺寸截圖
- 若要平板支援，另外補平板圖

## iPhone 建議
- 至少準備 6.7 吋或主力尺寸截圖
- 若有需要，可補 6.5 / 5.5 吋

## 建議順序
1. 先準備 5 張最核心畫面
2. 再補 2 到 3 張次要功能圖
3. 最後統一命名與整理資料夾
