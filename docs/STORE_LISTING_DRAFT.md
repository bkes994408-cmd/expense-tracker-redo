- 用簡潔直覺的方式記帳、管理預算、追蹤定期帳目與匯出 CSV。

## 完整說明（長版）
Expense Tracker Redo 是一款以清楚、快速、低干擾為核心的記帳工具。

你可以用它：
- 快速新增收入與支出
- 依月份查看交易紀錄
- 管理定期帳目與下次扣款日期
- 設定分類預算與儲蓄目標
- 匯出 CSV 進一步整理資料

### 主要功能
- 交易新增 / 編輯 / 刪除
- 搜尋、排序、分類篩選
- 月份切換與月支出趨勢
- 定期帳目管理
- 預算與目標追蹤
- CSV 匯出（當月 / 全部 / 分類）
- 深色模式與風格切換

### 適合誰
- 想要簡單記帳，不想被複雜功能干擾的人
- 想掌握每月支出與預算的人
- 需要整理個人收支 CSV 的人
