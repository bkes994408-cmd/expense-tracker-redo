# Screenshot Capture Playbook

最後更新：2026-04-18

這份不是只列要拍什麼，而是直接寫成操作順序。

## 拍攝前先做
1. 準備一致的測試資料
2. 確認沒有私人資料
3. 決定這輪用淺色或深色模式
4. 確保 Reports 頁有真實支出資料
5. 確保至少有：
   - 6~10 筆交易
   - 2 個 recurring
   - 2 個 goals
   - 3 個 budgets 有值

## 建議拍攝順序
### Shot 1. Home 總覽
1. 打開 app
2. 進到 Home
3. 確認可看到摘要、預算、目標
4. 截圖

### Shot 2. Transactions 列表
1. 進到 Transactions
2. 顯示搜尋 / 篩選 / 排序狀態
3. 確認列表裡同時有收入與支出
4. 截圖

### Shot 3. 新增交易
1. 點 FAB
2. 選一個分類
3. 顯示金額輸入與備註預設選項
4. 截圖 modal

### Shot 4. Recurring
1. 在 Transactions 切到定期帳目
2. 確認有定期項目與下次扣款日期
3. 截圖

### Shot 5. Reports
1. 進到 Reports
2. 確認有月支出趨勢
3. 不要用空狀態
4. 截圖

### Shot 6. Budget / Goals
1. 留在 Reports
2. 切到預算或目標
3. 顯示有內容的狀態
4. 截圖

### Shot 7. Settings
1. 進到 Settings
2. 顯示幣別、月起始日、深色模式等設定
3. 截圖

### Shot 8. CSV 匯出
1. 在 Settings 找到匯出 CSV 區塊
2. 選一個 scope
3. 顯示筆數預覽與檔名預覽
4. 截圖
